# Nix Tech Agent Roadmap

## Goal

Define future specialist agents deliberately instead of creating them ad hoc.

## Priority buckets

### Tier 1 — likely early specialists

Create these first when the base runtime is ready and repeated work appears:

- frontend specialist
- backend specialist
- testing specialist
- architecture specialist
- docs specialist

### Tier 2 — stack-specific specialists

Promote only after repeated usage proves the need:

- React specialist
- Next.js specialist
- TypeScript specialist
- Python specialist
- FastAPI specialist
- Tailwind specialist
- Docker specialist

### Tier 3 — workflow specialists

- PR/review specialist
- issue-writing specialist
- refactor specialist
- migration specialist

## Promotion checklist

- [ ] The technology is used frequently
- [ ] The work has non-trivial conventions
- [ ] Repeated prompts are already visible
- [ ] A dedicated skill exists or is clearly insufficient
- [ ] The specialization would reduce errors or context load

## Recommendation

Do not start by creating one agent per technology. Start with a few strong skills, then promote the patterns that prove themselves.
