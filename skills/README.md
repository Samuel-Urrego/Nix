# Skills

This folder stores reusable project skills for Nix.

## Suggested structure

```text
skills/
├── README.md
└── {skill-name}/
    ├── SKILL.md
    ├── assets/
    └── references/
```

## Rule

If the task pattern is repeated and stable, create a skill. If it is broad, unstable, or one-off, keep it out of `skills/`.
